### ST表
静态查询类问题（不需要修改）

ST表的核心思想：动态规划+倍增
设计 $dp[i][j]$ 
1. 状态：$dp[i][j]$表示以 $i$ 为起点，长度为 $2^j$ 的区间信息$[i,i+2^j-1]$
2. 状态转移方程：$dp[i][j]=max(dp[i][j-1],dp[i+(1<<(j-1)][j-1])$
3. 初始化：$dp[i][0] = a[i]$
4. 答案：区间查询 $[l,r]$ 分两种情况
     - 用若干个不重叠的区间拼接出 $[l,r]$
	    将 $len = r-l+1$ 拆分成不同长度的区间，然后拼接
	    $O(logn)$
	    求和，求乘积，不能重叠，重复计算会出错
	  - 用若干足够大存在重叠的区间覆盖 $[l,r]$
	    一般来说只需要两个区间覆盖即可
	    求最大的 $x$ 满足 $2^x<=len$
	    $[l,l+2^x-1] + [r-2^x+1,r]$
	    $O(1)$
	    比如求最值，允许重叠，重复计算不影响结果
```cpp
(1)用若干个不重叠的区间拼接出 [l,r]
int query(int l, int r){
	int ans = 0;
	for (int i = 0; i <= 30; ++i){
		if (l + (1 << i) - 1 <= r){
			ans += dp[l][i];
			l += 1 << i;	
		}	
	}
}
(2)用若干足够大存在重叠的区间覆盖 [l,r]
int query(int l, int r){
	int x = log2(r - l + 1);
	return max(dp[l][x], dp[r - (1 << x) + 1][x]);
}

int dp1[100000][30];
void init1(){
	for (int j = 1; (1 << j) <= n; ++j){
		for (int i = 1; i + (1 << j) - 1 <= n; ++i){
			dp1[i][j] = max(dp1[i][j - 1], 
						   dp1[i + (1 << (j - 1)) - 1][j - 1]);	
		}	
	}
}

int dp2[30][100000];
void init1(){
	for (int j = 1; (1 << j) <= n; ++j){
		for (int i = 1; i + (1 << j) - 1 <= n; ++i){
			dp2[j][i] = max(dp2[j - 1][i], 
						   dp2[j - 1][i + (1 << (j - 1)) - 1]);	
		}	
	}
}
```

$dp2 +init()$ 的运行效率高于 $dp1 + init()$
跟内存存储有关，内存中存储数组 **行优先**
$int\ a[4][3]$
$\to a[0][0]\to a[0][1]\to a[0][2]\to a[1][0]\to a[1][1]\to a[1][2]\to a[2][0]\to a[2][1]\to a[2][2]$
缓存命中，连续的缓存命中率高，访问效率极高
但是如果缓存命中率低，那么会额外花费很多的时间去重新建立缓存

### 树状数组
类似于简化版的线段树
树状数组其实就是一种支持修改的前缀数组
```cpp
//lowbit(x) 的结果是 x 的最低位 1 对应的位权
int lowbit(int x){
	return x & -x;
}
```
为什么这个计算方式可以取到最低位的 $1$？
因为在计算机中，存储数字采用了原码，反码，补码
对于正数：原码=反码=补码
对于负数：反码=原码按位取反，补码=反码+1

树状数组的核心：跟倍增比较相似，但是不一样
原理都是预处理出足够的区间，用这些区间能拼接出需要的信息
$A[i]$ 是数字
$tree[i]$ 维护以 $i$ `结尾` ，长度为 $lowbit(i)$ 的区间信息
这样的区间能不能拼接出任意区间？ $[3,25]$
$tree[25]->[25,25]$
$tree[24]->[17,24]$
$tree[16]->[1,16]$
所以 $tree[i]$ 不能保证任意区间都存在，但是由于二进制的特性，按这种方式从 $r$ 出发拼接区间，一定能得到 $[1,r]$ 的区间信息
所以 $tree[i]$ 只能保证得到前缀和的信息

所以如果想要得到 $[l,r]$ 的信息，只能利用 $[1,r] - [1,l-1]$ 来得到
所以只能用来求可以进行删除的区间信息

所以一般树状数组仅用于可维护前缀和的信息

1. 查询区间和
```cpp
int ask(int l, int r){
	return query(r) - query(l - 1);
}
int query(int x){
	int ans = 0;
	while (x > 0){
		ans += tree[x];
		x -= lowbit(x);	
	}
	return ans;
}
```

4. 区间最值查询（意味着我们需要想办法拼接出 $[l,r]$）
```cpp
比如 [2,25]
第一个区间 tree[25] = [25,25] 可用
第二个区间 tree[24] = [17,24] 可用
第三个区间 tree[16] = [1,16] 不能用，那么单独拼接 [16,16]
第四个区间 tree[15] = [15,15] 可用
第五个区间 tree[14] = [7,14] 可用
第六个区间 tree[6] = [3,6] 可用
第七个区间 tree[2] = [1,2] 不能用，那么单独拼接 [2,2]
O(log^2n)
void query_max(int l, int r){
	int ans = -1;
	while (l <= r){
		//先求出 tree[r] 对应的左端点 [left, r]
		int left = r - lowbit(r) + 1;	
		if (left < l){
			//当前区间超出了查询的范围
			//单独更新 [r,r]
			ans = max(ans, A[r]);
			r--;	
		} else {
			//当前区间可用，则直接拼接区间
			ans = max(ans, tree[r]);
			r -= lowbit(r);
		}
	}
	return ans;
}
```
