STANDALONE CLOUD DRIVE

从云盘功能里抽出的自包含版本：单个 HTML 文件、零依赖，放进任意 GitHub Pages 仓库即可使用，不需要 Jekyll 或任何框架。

研究记录
1. 自动从访问地址推断「用户名 / 仓库名」，并读取仓库默认分支，避免手改常量出错。
2. 列目录走 GitHub API，下载走 raw 直链，列表带五分钟本地缓存。
3. 托管在 GitHub Pages 之外时，只需填写仓库名与分支两个常量即可。
