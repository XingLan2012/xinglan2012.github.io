HOSTING A CLOUD DRIVE

科室：档案科
编目范围：2026-09-11
相关人物：星澜 / Xinglan
访问范围：PUBLIC AREA

一篇写给别人的教程：如何把 GitHub 仓库当作文件分发站，fork 之后用上云盘功能，全程不需要服务器与后端。

研究记录
1. 讲清原理（API 列目录 + raw 直链下载）与边界（单文件 100 MB 上限、仅公开文件、私有仓库不可用）。
2. 记录了默认分支写错会导致「能列出文件、但下载全 404」这个坑，以及自动识别分支的写法。
3. 附中文文件名编码、超大文件走 Release 分发、批量上传命令与 API 限流说明。
