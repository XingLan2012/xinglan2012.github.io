Toolcall 工具

使用 toolcall 时，需用  
```toolcall  
```  
包裹命令，来告诉执行器这里有指令需要执行。

---

## 1.1 注释
```toolcall  
//输入此操作的目的，这将会让用户知道你在干什么  
/*可以用这种方式来进一步精细化注释*/  
```

---

## 1.2 返回
当你的命令执行完之后，用户会以  
```tc_return_start  
```  
代码块的形式包裹起来返回内容返回给你。一般命令执行时当有新的输出时会把新的输出同步给你，如果1分钟内没有返回用户会用代码块包裹起来告诉你 `"No Return In 1 Minute"`，这之后会每分钟报告一次。  
如果意外（被）终止了，则会返回相关信息，会用  
```tc_error_start  
```  
包裹。

## 1.3 命令

### 1.3.1 files 命令
用于文件系统操作。

- **files read** `[目标文件]` `<打开方式>`  
  进行读取操作。打开方式可填 `文本文件` 或 `二进制`，默认文本文件。  
  若文件大小 ≤200KB，则一次性返回全部内容；若超过则返回前 200KB。若想继续阅读，追加命令 `files read trace`（会继续发送后续 200KB，可多次调用直至读完）。  
  不能读取时返回错误 `FILE_CANNOT_READ:[详细报错]`。

- **files write** `[目标文件]` `<写入方式>` `[代号]`  
  写入方式默认 `文本`（也可 `二进制`）。  
  在 toolcall 代码块后追加一个代码块：
  ```[刚才的那个代号]
  （要写入的内容）
  ```
  若文件为空则直接写入，若不为空则在末尾追加。

- **files search** `[目标文件]` `<搜索方式>` `[关键词]`  
  搜索方式可选 `文本` 或 `二进制`。返回所有匹配项所在行、列数及上下文（前后各 3 行）。  
  可附加参数 `-case` 区分大小写，`-regex` 使用正则表达式。

- **files insert** `[目标文件]` `行` `列` `[代号]`  
  在指定行、列位置插入内容（行列从 1 开始计数）。  
  代码块格式同上。

- **files edit** `[目标文件]` `[代号1]` `[代号2]` `<参数>`  
  替换内容。代码块：
  ```[代号1]
  要替换的内容
  ```
  ```[代号2]
  替换为
  ```
  默认替换所有匹配项。若加参数 `-selectedit`，则工具返回所有匹配项及其起始/结束行列数和唯一代号，你再用 `edit trace [代号1] [代号2] ...` 选择替换哪些。

- **files setcode** `[编码方式]`  
  设置当前操作文件的编码（如 UTF-8、GBK、ASCII 等），影响后续读写。

- **files delet** `[文件名]`  
  删除文件（不进回收站）。

- **files new** `[文件名]`  
  新建空文件（若已存在则报错）。

- **files newf** `[文件夹名]`  
  新建文件夹。

- **files deletf** `[文件夹名]`  
  删除空文件夹（若非空则报错）。

- **files code** `[文件名]`  
  获取文件的检测编码方式。

- **files cd** `[路径]`  
  切换当前工作目录，格式与 Windows `cd` 相同（支持 `.`、`..`、盘符切换）。

- **files search -allfiles** `[路径]` `[内容]`  
  在指定路径下递归搜索所有文件内容（支持通配符），返回匹配的文件名及行号。

- **files ls** `[路径]`  
  列出路径下的文件和文件夹，显示大小、修改时间。

- **files info** `[目标文件]`  
  返回文件元信息（大小、创建时间、修改时间、属性等）。

- **files copy** `[源文件]` `[目标文件]`  
  复制文件。

- **files move** `[源文件]` `[目标文件]`  
  移动或重命名文件。

### 1.3.2 exec 命令
在 PowerShell 中执行命令。

- **exec** `[会话名]` `[powershell命令]`  
  创建（或复用）会话并执行命令，返回输出（stdout/stderr）。

- **exec kill** `[会话名]`  
  结束会话并释放资源。

- **exec about** `[会话名]`  
  查询会话信息（启动时间、PID、当前路径、权限等）。

- **exec getadmin** `[会话名]`  
  尝试提权，弹出 UAC 询问用户。

- **exec list**  
  返回所有活跃会话名列表。

- **exec history** `[会话名]`  
  返回该会话的历史命令记录（自动记录到本地 memory 文档）。

- **exec timeout** `[会话名]` `[毫秒]`  
  设置该会话命令执行的超时时间（默认 30000ms）。

- **exec env** `[会话名]` `[变量名]` `[值]`  
  设置/读取环境变量（不带值则读取）。

> **注意**：会话不结束则持续运行，务必及时 kill。**禁止使用 PowerShell 进行文件读写操作**（应使用 files 命令）。

---

### 1.3.3 cmd 命令
在 CMD 中执行命令，用法与 exec 类似。

- **cmd** `[会话名]` `[cmd命令]`
- **cmd kill** `[会话名]`
- **cmd about** `[会话名]`
- **cmd getadmin** `[会话名]`
- **cmd list**
- **cmd history** `[会话名]`
- **cmd timeout** `[会话名]` `[毫秒]`
- **cmd env** `[会话名]` `[变量名]` `[值]`

> **禁止使用 CMD 进行文件读写操作**。

### 1.3.4 cur 命令
模拟鼠标操作，带有人性化随机抖动。

- **cur move** `[坐标]`  
  移动鼠标到 (x,y)，移动过程带随机抖动。

- **cur click** `[L/M/R]` `<坐标>`  
  单击左/中/右键，若省略坐标则在当前位置单击。

- **cur doubleclick** `[L/M/R]` `<坐标>`  
  双击。

- **cur hold** `[L/M/R]`  
  按住指定键不放。

- **cur release** `[L/M/R]`  
  松开指定键。

- **cur PageUp** `[滚动距离]`  
  向上滚动滚轮（距离单位：格数，默认 3）。

- **cur PageDown** `[滚动距离]`  
  向下滚动滚轮。

- **cur drag** `[起点坐标]` `[终点坐标]` `[L/M/R]`  
  按住指定键从起点拖拽到终点，释放。

- **cur getpos**  
  返回当前光标位置。

- **cur speed** `[速度因子]`  
  设置移动速度（0.5~5.0，默认 1.0）。

---

### 1.3.5 run 命令
启动外部程序。

- **run** `<权限>` `[会话名]` `[目标文件]` `<参数>`  
  权限：`-a` 管理员，`-u` 普通用户（默认）。可附带启动参数。  
  若申请管理员则会弹出 UAC 询问。

- **run about** `[会话名]`  
  返回进程 PID、权限、工作目录、窗口句柄、命令行等。

- **run list**  
  返回所有由 run 启动的会话名。

- **run kill** `[会话名]`  
  强制结束该进程。

- **run wait** `[会话名]`  
  等待进程结束并返回退出码。

---

### 1.3.6 screen 命令（实验性）
利用 Windows UI Automation 读取屏幕界面元素。

- **screen** `<目标窗口>`  
  若未指定目标窗口则读取整个屏幕。返回结构化文本（窗口标题、控件类型、坐标、文本内容等），以 JSON 或缩进格式呈现。

- **screen find** `[关键词]`  
  在当前屏幕中搜索包含关键词的 UI 元素，返回其位置和属性。

- **screen focus** `[窗口标题/句柄]`  
  将指定窗口置于前台。

---

### 1.3.7 网络操作
内嵌 WebView2，支持浏览器自动化及原始套接字。

- **net new** `[会话名]`  
  新建一个 WebView2 页面会话。

- **net** `[会话名]` `[javascript代码]`  
  在页面中注入并执行 JS，返回执行结果（JSON 序列化）。

- **net getsource** `[会话名]`  
  获取当前页面的完整 HTML 源代码。

- **net navigate** `[会话名]` `[URL]`  
  导航到指定 URL。

- **net click** `[会话名]` `[CSS选择器]`  
  模拟点击页面元素。

- **net type** `[会话名]` `[CSS选择器]` `[文本]`  
  在输入框中键入文本。

- **net screenshot** `[会话名]` `<文件路径>`  
  截取当前页面（可保存为图片）。

- **net close** `[会话名]`  
  关闭页面会话。

**原始套接字部分：**

- **socket raw** `[接口]` `[以太帧数据]`（hex 字符串）  
  直接发送自定义以太网帧（需管理员权限）。

- **socket udp** `[目标IP]` `[端口]` `[数据]`  
  发送 UDP 数据包。

- **socket tcp** `[目标IP]` `[端口]` `[数据]`  
  建立 TCP 连接并发送数据，返回响应。

- **socket listen** `[端口]` `[协议]`  
  在本地监听端口（TCP/UDP），返回接收到的数据。

### 1.3.8 websearch 命令
搜索引擎检索。

- **websearch** `<站点>` `[内容]`  
  站点默认百度，也可指定 `bing`、`google` 等（需工具支持）。返回前 50 条结果（标题、关键词上下文、链接），自动过滤广告。  
  加 `--trace` 显示下 50 条。

- **websearch getinto** `[链接]` `<参数>`  
  进入链接，返回 HTML 源代码。若加 `--markdown`，工具将 HTML 编译为 Markdown 格式再返回。

- **websearch suggest** `[关键词]`  
  返回搜索引擎的联想词建议。

### 1.3.9 pic 命令
图像识别与描述。

- **eyes** `[文件路径/图片url]`  
  将图片发送给 DeepSeek 网页端识图模式，返回对图片的详细描述。

- **pic ocr** `[文件路径/图片url]`  
 发给Deepseek网页端提取图片中的文字。

- **pic resize** `[源文件]` `[目标文件]` `[宽]` `[高]`  
  调整图片尺寸。

- **pic convert** `[源文件]` `[目标文件]` `[格式]`  
  转换图片格式（如 png→jpg）。

### 1.3.10 kbd 命令
模拟键盘操作。

- **kbd** `[键盘按键]`  
  模拟按下并立即释放单个按键（如 `kbd Enter`）。

- **kbd press** `[键盘按键]`  
  按住按键（不释放）。

- **kbd release** `[键盘按键]`  
  松开按键。

- **kbd hotkey** `[按键1]` `[按键2]` `[按键3]` ...  
  同时按下多个键（组合键），然后按相反顺序释放。

- **kbd type** `[文本]`  
  逐字输入一段文本（支持 Unicode）。

- **kbd delay** `[毫秒]`  
  设置每次按键之间的延迟（默认 50ms）。

- **kbd macro** `[宏名称]` `[按键序列]`  
  定义并执行宏（例如 `kbd macro save "Ctrl+S"`）。

### 1.3.11 knowledge 命令
用于加载、查询和管理知识库（支持本地文件/文件夹或云端链接）。

- **knowledge** `[路径]`  
  加载本地路径（文件或文件夹）作为知识库。若为文件夹，则递归索引其中所有文本文件（.txt, .md, .pdf, .docx 等，需工具支持解析）。加载后可通过 `knowledge search` 检索。

- **knowledge** `[链接]`  
  加载云端知识库（如 WebDAV、私有 API 端点、或公共知识库 URL）。工具会尝试获取索引文件或直接下载内容。支持 `https://`、`webdav://` 等协议。

- **knowledge search** `[关键词]` `<知识库名称>`  
  在当前已加载的知识库中搜索关键词，返回相关片段及来源（文件路径或链接）。若不指定知识库名称，则搜索所有已加载的知识库。

- **knowledge list**  
  列出所有已加载的知识库及其状态（本地/云端、索引条目数、最后更新时间）。

- **knowledge remove** `[知识库名称]`  
  从内存中卸载指定知识库。

- **knowledge sync** `[知识库名称]`  
  手动同步云端知识库（若已加载云端源），更新本地缓存。

- **knowledge info** `[知识库名称]`  
  显示该知识库的详细信息（来源、大小、条目数、支持的查询字段等）。

- **knowledge export** `[知识库名称]` `[目标文件]`  
  将知识库导出为结构化文件（如 JSON、CSV），便于备份或迁移。

使用示例：
```toolcall
knowledge C:\my_docs
knowledge https://api.example.com/kb/tech
knowledge search "如何配置网络" tech
```
返回结果遵循统一的 `tc_return_start` 格式。若加载失败，会返回 `KNOWLEDGE_LOAD_ERROR:[详细报错]`。

## 1.4 会话
Toolcall 本身也支持多会话管理，用于隔离执行环境。

- `toolcall [会话名]` – 创建或进入指定会话（后续命令在该会话上下文中执行）。
- `toolcall getadmin [会话名]` – 为会话提权（需用户同意）。
- `toolcall list` – 返回所有会话名。
- `toolcall about [会话名]` – 显示会话信息（创建时间、权限、当前目录等）。
- `toolcall history [会话名]` – 返回该会话的命令历史（自动记录到 memory 文档）。
- `toolcall kill [会话名]` – 销毁会话，清理资源。
- `toolcall rename [旧名] [新名]` – 重命名会话。

## 1.5 设置
全局配置项。

- `easyadmin true` – 向用户申请后续管理员操作不再弹窗（会弹最终确认框）。
- `easyadmin false` – 恢复每次提权都弹窗。
- `set timeout [毫秒]` – 设置所有命令的默认超时时间。
- `set loglevel [debug/info/warn/error]` – 控制日志输出详细程度。
- `set default_editor [vim/notepad/...]` – 设置 files edit 的备用编辑器。

---

## 1.6 记忆
- `memory [内容]` – 搜索本地记忆文档（memory 文件），返回相关条目。  
- `memory add [标签] [内容]` – 手动添加一条记忆。
- `memory forget [标签/内容]` – 删除匹配的记忆。

---

## 1.7 系统与辅助命令

- **sys info** – 返回操作系统版本、CPU、内存、磁盘使用情况。
- **sys clipboard** `<get/set>` `[内容]` – 获取或设置剪贴板内容。
- **sys sleep** `[毫秒]` – 暂停执行指定时间。
- **sys beep** `[频率]` `[持续时间]` – 发出蜂鸣声。
- **help** `[命令名]` – 显示该命令的详细用法。
