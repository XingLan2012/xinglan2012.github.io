    说明
    

      分段方式：整份明文 → Base64 → 每 48000 字符一段写入 Clash/parts/seg-NN.txt，
      Clash/manifest.json 记录段顺序、总字节数与 SHA-256。页面拼接后用 WebCrypto 核对 SHA-256，
      缺段或被改动都会明确报错。
    

    

      这只解决「单个文件里直接躺着 proxies: / password: 被规则扫描器命中」的问题，
      不是加密：把分段按顺序拼起来就能还原明文，请勿把本页当保密手段。
    

    

      更新配置（本地工具不入库）：node _gen_clash_parts.mjs 重新生成分段与清单，然后
      git add Clash/parts Clash/manifest.json && git commit && git push。
    

  


  

    导入方式：下载得到 config.yaml 后，在 Clash / Clash Verge / mihomo 里「导入本地配置文件」即可。

    明文含节点密码与 UUID，请勿转发到公开位置。
