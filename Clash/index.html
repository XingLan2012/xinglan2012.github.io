    技术说明
    

      加密算法：先 gzip 压缩，再用 AES-256-GCM（128 位认证标签）加密；
      密钥由 PBKDF2-HMAC-SHA256 从密码派生，迭代 600000 次，盐值与 IV 每次重新生成。

      密码校验：文件里不保存明文密码，只保存一份同样经 PBKDF2-SHA256 派生的校验值（check），
      输入错误可立即提示；即使有人改掉校验值，GCM 认证标签也会让解密失败。

      解密与统计全部通过浏览器原生 WebCrypto 完成，页面不发起任何上传请求。
    

    

      本地工具（不在仓库里）：CLASH_PW='密码' node _clash_crypt.mjs encrypt ~/clash/config.yaml Clash/config.enc.json
      —— 重新加密后 git add Clash/config.enc.json && git commit && git push 即可。
    

  


  

    提示：解密后的文件包含节点密码 / UUID，请勿转发到公开位置。

    加密文件直链：Clash/config.enc.json（同时可用于 Clash 客户端的远程订阅导入场景：先本地解密再导入）。
