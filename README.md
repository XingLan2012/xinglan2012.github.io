# ✦ Starlight Realm — Utopia Across the Shore

[![GitHub Pages](https://img.shields.io/badge/blog-Starlight_Realm-ffd700?style=flat-square)](https://xinglan2012.github.io)
[![license](https://img.shields.io/github/license/XingLan2012/xinglan2012.github.io?style=flat-square)](LICENSE)

**Starlight Realm (星澜之境)** — a small world built by Xinglan. Here you'll find code, algorithms, Minecraft stories, poems and thoughts written late into the night.

> Meeting you is a moment of breathtaking wonder, like summer flowers igniting the fire of life.  
> Parting is a quiet return, like autumn leaves paving the road home.

---

## ✦ Features

| Feature | Description |
|---------|-------------|
| 📝 **Blog** | OI algorithms, daily life, Minecraft stories |
| ⌨ **OIer Notes** | Algorithm study notes under `/ioer/` |
| 🎴 **Fortune** | Daily fortune draw (Da-ji to Da-xiong) with poems |
| 🎵 **Music Player** | 65 C418-style ogg tracks, global float player |
| 🤖 **AI Assistant** | Powered by AgnesAPI, smart Q&A |
| ☁ **Cloud Drive** | File sharing via `/pan/` with mirror nodes |
| ❄ **Crystal Pendant** | Left-side navigation panel |

### Interactive Effects

- **Starfield** — Animated stars + shooting meteors on homepage
- **Click Effects** — ✦✧⋆ burst on click + mouse trail
- **Splash Animation** — Daily welcome animation on load
- **Dynamic Background** — bg1~bg3 rotating background

## ✦ Tech Stack

| Tech | Purpose |
|------|---------|
| [Jekyll](https://jekyllrb.com/) + [TeXt Theme](https://github.com/kitian616/jekyll-TeXt-theme) | Static blog framework |
| GitHub Pages | Hosting & deployment |
| [Agnes API](https://apihub.agnes-ai.com) | AI chat |
| HTML / CSS / JavaScript | Frontend & interactive effects |
| LocalStorage | Fortune records, music prefs, file cache |

## ✦ Local Development

```bash
# Install dependencies
gem install jekyll bundler
bundle install

# Start local server
bundle exec jekyll serve

# Visit http://localhost:4000
```
